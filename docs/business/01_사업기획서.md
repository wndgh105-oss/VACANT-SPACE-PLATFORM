## 2. 문제 정의

### 2-1. 예비 창업자 측 — "첫 발을 못 뗀다"

소형 요식/리테일 창업의 초기 고정비는 개인이 한 번에 감당하기 어려운 구조입니다. 가정 기준, 서울 비핵심 상권 15평 카페 창업 시:

| 항목 | 가정 금액 |
|---|---|
| 보증금 | 3,000만 원 |
| 권리금 | 2,000만 원 |
| 인테리어 (15평 × 150만 원) | 2,250만 원 |
| 주방·에스프레소 장비 | 1,500만 원 |
| 간판·POS·집기 | 500만 원 |
| 초기 운영자금 3개월 | 1,500만 원 |
| **합계** | **약 1억 750만 원** |

문제의 본질은 금액 자체보다 **구조**입니다.

1. **비가역성** — 인테리어·권리금·장비 구매는 실패 시 대부분 회수되지 않습니다.
2. **최소 계약 단위의 경직성** — 상가 임대차는 통상 1~2년 단위라, "3개월만 해보고 판단한다"는 선택지가 시장에 없습니다.
3. **검증 없는 올인** — 상권·메뉴·가격·본인 적성 어느 것도 검증되지 않은 상태에서 전 재산 규모의 의사결정을 합니다.

### 2-2. 건물주 측 — "비어 있는 동안 수익이 0원이다"

- 공실은 **월세 0원 + 관리비 자부담 + 건물 노후화 + 상권 활력 저하**의 4중 손실입니다.
- 그럼에도 건물주가 단기 임대를 꺼리는 이유는 **위험 회피**입니다: 원상복구 분쟁, 임차인의 갱신요구권·권리금 회수기회 주장, 시설 훼손, 민원, 세무 처리 불확실성.
- 즉 공실이 안 팔리는 건 수요가 없어서만이 아니라, **단기 계약을 안전하게 만들어 주는 표준 절차가 없어서**입니다.

### 2-3. 정보 비대칭

- 상권 데이터(유동인구·업종별 생존율)는 공공에 존재하지만, **"이 공실 + 이 업종 + 내 예산"으로 번역해 주는 도구가 없습니다.**
- 예비 창업자는 "총 얼마 드는지"를 계약 직전까지 모릅니다. 임대료·장비·인허가·보험이 각각 다른 채널에 흩어져 있습니다.
- 장비 렌탈사는 "지금 창업을 결심한 사람"에게 접근할 채널이 없어 마케팅 효율이 낮습니다.

### 2-4. 문제의 요약

> 공급(공실)과 수요(창업 의향)는 둘 다 존재하는데, **거래 단위가 서로 맞지 않아** 매칭이 일어나지 않는다.
> 공급은 "24개월 단위"로만 팔고, 수요는 "2개월치 위험"만 감당할 수 있다.

## 3. 해결책 및 핵심 가치 제안

### 3-1. 해결책 구조

빈자리는 **거래 단위를 잘게 쪼개고, 쪼갠 만큼의 리스크를 표준 절차로 흡수**합니다.

```
[기존]   24개월 계약 + 1억 초기비용 + 실패 시 전액 손실
   ↓
[빈자리]  2개월 계약 + 약 500~900만 원 + 손실 한정 + 성공 시 연장/이전/정식창업
```

3개 레이어로 구현합니다.

| 레이어 | 내용 |
|---|---|
| **① 공간** | 공실을 1~6개월 단위 "단기 이용" 상품으로 등록. 무권리·최소보증금·즉시입주 여부를 표준 필드로 노출 |
| **② 장비** | 업종별 모듈형 장비 패키지(카페/팝업/사무실/스터디)를 월 렌탈로 결합. 구매가 아니라 반납 가능한 렌탈이므로 실패 비용이 고정비가 아닌 변동비가 됨 |
| **③ 신뢰** | 표준 단기 이용 계약 템플릿, 원상복구 범위 사전 합의 체크리스트, 본인인증, 보증·배상책임보험 연계, 인허가 체크리스트 |

### 3-2. 고객별 가치 제안

**예비 창업자에게**
> "1억을 걸기 전에, 800만 원으로 두 달 장사해 보세요."
> 실패하면 장비를 반납하고 끝냅니다. 잘되면 그 자리에서 연장하거나 더 좋은 자리로 옮깁니다.

**건물주에게**
> "공실 상태로 6개월 두는 것보다, 2개월씩 세 번 채우는 게 낫습니다."
> 원상복구 범위와 계약 종료일이 처음부터 확정된, 분쟁 가능성이 통제된 단기 임차인을 연결합니다.

**장비 렌탈사에게**
> "창업을 결심한 순간의 고객을, 견적 화면 안에서 만나세요."
> 개별 영업 없이 패키지 단위로 노출되고, 계약 성사 시점에 배송·설치가 확정됩니다.

**지역 고객에게**
> "우리 동네에 계속 새 가게가 생깁니다."
> 죽어 있던 공실이 2개월마다 새 팝업·카페로 바뀌는 회전형 상권.

### 3-3. 왜 지금인가 (가정 · 검증 필요)

- 고금리·소비 위축 이후 상가 공실률 상승 → 건물주의 단기 임대 수용도 증가 *(통계 재확인 필요)*
- 팝업스토어 문화 정착으로 "짧게 열었다 닫는 매장"에 대한 소비자 거부감 소멸
- 중고·렌탈 시장 성숙으로 상업용 주방장비 렌탈 공급자 확보 가능

## 4. 고객 세분화

### 4-1. 예비 창업자 / 임차인 (핵심 수요)

| 세그먼트 | 프로필 | 니즈 | 예상 비중 |
|---|---|---|---|
| **A. 첫 창업 실험형** (핵심) | 25~34세, 직장인 또는 퇴사 직후, 가용 자금 1,000~3,000만 원, 카페·디저트·소품 | "적성과 상권을 검증하고 싶다" | 45% |
| **B. 온라인→오프라인 전환형** | 스마트스토어·인스타 판매자 | "고객 반응을 직접 보고 싶다" | 25% |
| **C. 브랜드 팝업 운영형** | 소규모 브랜드/기업 마케팅 담당 | "2~4주 단기 공간 + 집기 일괄" | 20% |
| **D. 재도전형** | 폐업 경험자, 소자본 재기 | "다시 크게 못 건다" | 10% |

**초기 집중 타깃: A + C** (지불 의사와 의사결정 속도가 가장 높음)

### 4-2. 공실 소유자 / 임대인 (핵심 공급)

| 세그먼트 | 특징 | 설득 포인트 |
|---|---|---|
| **장기 공실 보유 개인 건물주** (핵심) | 3개월 이상 공실, 1~3층 소형 상가 | 공실 기간의 기회비용 + 분쟁 통제 |
| 신축·리모델링 직후 건물주 | 임차인 모집 중 공백 | 정식 임차 전 브릿지 수익 |
| 기존 임차인의 유휴 공간 | 낮 시간 미사용 술집 등 | 전대차 → **법적 검토 필수 (9-1 L3)** |
| 지자체·공공 유휴공간 | 청년몰, 도시재생 공간 | 협약 기반, 초기 공급 확보에 유리 |

### 4-3. 장비 렌탈 파트너 (공급 보조)

- 상업용 주방장비 렌탈사, 사무가구 렌탈사, POS·키오스크 사업자, 간판·사인물 제작사
- 니즈: 신규 창업 고객 확보 채널, 계약이 확정된 리드
- 초기 확보 목표: 업종별 최소 2개사 (가격 비교가 성립하는 최소 조건)

### 4-4. 지역 고객 / 방문객 (수요의 수요)

직접 과금 대상은 아니지만 **입점 창업자의 성패를 결정**하는 최종 고객입니다. 플랫폼은 "이전 소식" 티저·오픈 알림으로 이들을 창업자에게 연결해 창업자의 성공률을 높이고, 이는 재계약률(핵심 수익 지표)로 되돌아옵니다.

## 5. 핵심 서비스 및 사용자 여정

### 5-1. 핵심 서비스 5개

1. **단기 공실 탐색** — 지역·기간·예산·업종 가능 여부 기반 검색 (지도/목록 전환)
2. **모듈형 장비 패키지** — 업종별 스타터 패키지 선택 및 개별 품목 가감
3. **통합 견적** — 공간 + 장비 + 기간 합산 총비용/월비용/정식창업 대비 절감액
4. **예약·상담 요청 및 진행 상태 관리** — 요청 → 상담 → 확정 → 운영 → 종료/연장/이전
5. **이전 바이럴 (이전 소식)** — 이전 시 SNS 공유용 티저 카드·지도 힌트·오픈 카운트다운 랜딩 자동 생성

### 5-2. 창업자 여정 (시나리오 A~E)

```
① 인지    인스타/지역 커뮤니티에서 "두 달만 열어보는 카페" 콘텐츠 접촉
② 탐색    "성수동 / 2개월 / 월 150만 원 이하 / 카페 가능" 조건 검색
③ 비교    공간 3곳 비교 — 상권 요약·추천 업종·월 예상 비용
④ 구성    공간 선택 → [카페 스타터 패키지] 추가 → 기간 2개월
⑤ 견적    총 예상 비용 + "정식 창업 대비 절감액" 확인
⑥ 요청    [상담/예약 요청] 제출  ※ MVP는 데모 요청이며 실제 계약·결제 아님
⑦ 계약    운영자 중개 → 표준 단기 이용 계약 + 장비 배송·설치일 확정
⑧ 운영    창업자 대시보드에서 기간·비용·장비·잔여일 확인
⑨ 분기    [연장] / [이전 — 더 좋은 자리 추천] / [종료] / [정식 창업 전환]
⑩ 바이럴  "우리가 어디로 옮겼게요?" 티저 페이지 생성 → SNS 공유 → 신규 매장 방문 유도
```

### 5-3. 건물주 여정

```
공실 등록(주소·면적·월 이용료·가능 기간·업종 허용·설비) → 실사 → 노출
  → 문의/요청 수신 → 조건 협의 → 계약 요청 승인
  → 이용 기간 중 대시보드에서 잔여 기간·예상 수익 확인
  → 종료 D-14 알림 → 연장 제안 또는 자동 재노출
```

### 5-4. 장비 파트너 여정

```
파트너 등록 → 패키지/품목·월 렌탈료·배송 가능 지역 등록
  → 견적 화면에 자동 노출 → 계약 확정 시 배송·설치 요청 수신
  → 반납 일정 관리 → 정산
```

| 공간 대여 플랫폼 | 예약 UX 성숙 | **시간·일 단위**, "장사"가 아니라 "행사" 목적 |
| 공유오피스 | 표준화된 단기 계약 | **업종이 사무직으로 한정**, F&B·리테일 불가 |
| 팝업 전문 대행사 | 실행력 | **B2B 고가 대행**, 개인 창업자 접근 불가 |
| 장비 렌탈사 | 공급 능력 | **공간과 분리**, 창업자가 직접 조합해야 함 |

### 6-3. 차별화 전략 4가지

1. **번들링** — 공간과 장비를 *하나의 견적서*로 묶는다. 경쟁자는 둘 중 하나만 판다.
2. **거래 단위 혁신** — 1~6개월이라는, 시장에 없던 계약 단위를 표준 계약서와 함께 상품화한다.
3. **실패 비용의 변동비화** — 구매→렌탈, 장기→단기, 권리금→무권리. 창업 고정비를 구조적으로 제거한다.
4. **이전 바이럴 루프** — 창업자 이전 시 발생하는 "고객 이탈"을 플랫폼 콘텐츠(티저·미션·지도 힌트)로 전환한다. 창업자는 고객을 지키고 플랫폼은 무료 도달을 얻는다. 경쟁사가 복제하기 가장 어려운 자산.

### 6-4. 진입장벽 구축 순서

단기: 공급 선점(장기 공실 건물주 계약) → 중기: 표준 단기 계약·보험 상품 자체 설계 → 장기: 회전 데이터(어떤 상권·업종·기간이 성공하는가) 기반 추천 정확도

### 10-1. 진입 전략 — "1개 상권 장악 후 확장"

3. **첫 3개월 수수료 면제**로 공급 선점
4. **성공 사례 1건을 콘텐츠화** → 다른 건물주 설득 자산으로 재사용

```
   ↓
플랫폼이 [이전 소식 티저 페이지] 자동 생성
   · "우리가 어디로 옮겼게요?" 힌트 카드 3장
   · 흐릿하게 처리된 지도 + 반경 힌트
   · 오픈 D-day 카운트다운
   · 정답 참여자에게 오픈 첫날 쿠폰
   ↓
창업자가 자신의 SNS에 공유 → 기존 단골이 참여·재공유
   ↓
신규 매장 오픈일 대기 줄 형성 (이전으로 인한 고객 이탈 방지)
   ↓
티저 페이지 하단 "이 매장은 빈자리로 열었습니다" → 플랫폼 신규 유입
```

**왜 강력한가**
- 창업자에게 **자발적으로 공유할 이유**가 있습니다(내 매출을 지키기 위해). 플랫폼이 공유를 부탁할 필요가 없습니다.
- 이전이 발생할 때마다 반복되는 **구조적 획득 채널**입니다.
- 지역 고객이 참여하는 게임 형태라 **오프라인 상권에 직접 도달**합니다.

**KPI**: 티저 생성률(이전 건수 대비), 페이지당 방문자, 방문자→가입 전환율, 오픈 첫날 방문객 수

### 10-5. 브랜드 톤

지역 커뮤니티 마켓처럼 **따뜻하고 직관적이며 신뢰감 있는** 톤. 아이보리 배경 + 짙은 차콜 텍스트 + 테라코타 포인트. "부동산"의 언어가 아니라 "동네에서 뭔가 시작해 보는 일"의 언어를 씁니다. *(기존 플랫폼의 브랜드 자산은 사용하지 않으며, 사용성 관점만 참고합니다.)*
