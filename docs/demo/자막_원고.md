# 빈자리 데모 영상 — 자막 원고 및 스토리보드

- **길이**: 59.2초 (1280×800, 25fps)
- **원본**: `docs/demo/raw/*.webm` (Playwright 실제 브라우저 자동 조작 녹화)
- **변환본**: `docs/demo/demo.mp4` (H.264 / 3.26MB / 재생 확인 완료)
- **장면 스크린샷**: `docs/demo/scenes/01~18*.png`
- **녹화 스크립트**: `scripts/record-demo.ts` / **변환 스크립트**: `scripts/build-demo.mjs`

> 이 영상은 **실제로 실행 중인 MVP를 자동 조작해 녹화**한 것입니다. 정지 화면을 이어 붙인 것이 아닙니다.
> 다만 마지막 클로징 카드만 영상 아웃트로용 오버레이로 삽입했습니다(`outro()` 함수).
> 영상 속 결제·계약은 실제로 이루어지지 않으며, 화면 상단에 데모 고지가 상시 노출됩니다.

### 영상에서 쓰지 않은 표현 (의도적 배제)

오해를 만들 수 있어 아래 표현은 사용하지 않았습니다.

- "지금 바로 계약하세요", "결제 완료" 등 실제 거래가 일어난 듯한 문구
- "합법적으로 보장됩니다", "법적 문제 없습니다" 등 법률 판단 단정
- "실제 매물", "현재 임대 중인 공간" 등 실재 매물처럼 보이는 표현
- 실존 브랜드·플랫폼의 명칭이나 화면

## 재생성 방법

```bash
npm run dev          # 별도 터미널에서 개발 서버 실행
npm run seed         # 데모 데이터 준비 (한 번만)
npm run demo         # 녹화 + mp4 변환 (= demo:record && demo:build)
```

### mp4 변환

`scripts/build-demo.mjs` 는 ffmpeg를 아래 순서로 찾습니다.

1. `FFMPEG_PATH` 환경변수
2. 시스템 PATH의 `ffmpeg`
3. Playwright 번들 ffmpeg

⚠️ **Playwright 번들 ffmpeg는 webm(VP8) 전용 축소 빌드라 mp4 muxer가 없습니다.**
따라서 mp4 산출물을 만들려면 **일반 ffmpeg가 설치되어 있어야 합니다.**

```bash
# Windows
winget install Gyan.FFmpeg
# macOS
brew install ffmpeg
```

설치 후 `npm run demo:build` 를 다시 실행하면 `docs/demo/demo.mp4` 가 생성됩니다.
ffmpeg가 없는 환경에서는 `docs/demo/raw/*.webm` 파일을 그대로 재생하면 됩니다
(크롬·엣지·파이어폭스에서 바로 재생됩니다).
