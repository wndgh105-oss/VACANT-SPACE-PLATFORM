# 창업자(임차인) 화면 설계 스펙

- 작성일: 2026-09-02
- 관련 문서: [모두의창업_지원서_초안.md](../../../../모두의창업_지원서_초안.md)
- 범위: 단기 임대형 모듈 창업 플랫폼의 **창업자(임차인) 측 MVP 화면**만 다룬다. 건물주(임대인) 측, 운영자(관리자) 측 화면은 별도 스펙으로 분리한다.

## 1. 배경 및 목표

공실 건물주와 예비 창업자를 연결해, 최소 자본·단기 계약·모듈형 장비 렌탈로 오프라인 창업을 가능하게 하는 플랫폼([모두의창업_지원서_초안.md](../../../../모두의창업_지원서_초안.md) 참고)의 창업자용 웹 화면 구조를 정의한다.

목표: 창업자가 예산·업종·계약기간 조건으로 공실을 찾고, 해당 공실에 자동 연결된 업종별 장비 패키지를 함께 확인한 뒤, 신청/상담 요청까지 완료할 수 있는 화면 흐름을 제공한다.

## 2. 범위 결정 사항

| 항목 | 결정 |
|---|---|
| 플랫폼 형태 | 웹(반응형) 우선. 모바일 네이티브 앱은 이후 단계 |
| 결제 | MVP는 온라인 결제 없음. "신청/상담 요청"까지만 처리하고 계약·결제는 운영진이 오프라인으로 수동 진행 |
| 계정 시스템 | 이메일 기반 간단 회원가입/로그인 포함 (소셜 로그인은 확장 옵션으로 UI만 노출, MVP 기능 아님) |
| 장비 렌탈 결합 방식 | 공실 검색 결과에 업종별 장비 패키지가 자동 연결되어, 공실 상세 페이지 안에서 함께 노출됨 (별도 장비 선택 단계 없음) |
| 이번 스펙 범위 | 창업자(임차인) 화면만. 건물주/운영자 화면은 제외 |

## 3. 정보구조 (Sitemap)

채택 접근: **마켓플레이스형(A) + 선택적 추천 위젯(B) 하이브리드**. 필터 기반 검색을 기본 골격으로 하되, 홈 상단에 3단계 추천 위젯을 선택적 단축 경로로 제공해 초보 창업자의 의사결정 부담을 줄인다.

```
홈/검색 화면 ──(추천 위젯 진입)──▶ 추천 위젯(3단계) ──▶ 검색 결과 목록
     │                                                        │
     └────────────────(직접 필터 사용)──────────────────────────┘
                                                                 │
                                                                 ▼
                                                        공실 상세 페이지
                                                                 │
                                                    (비로그인 시 로그인 유도)
                                                                 │
                                                                 ▼
                                                      신청/상담 요청 폼
                                                                 │
                                                                 ▼
                                                   마이페이지 - 신청 현황
                                                   마이페이지 - 관심 목록(찜)
```

## 4. 화면별 상세

### 4.1 홈 / 검색 화면
- 상단: 서비스 슬로건 + "추천 위젯 시작하기" 버튼
- 필터 바: 가격대(구간 선택), 업종(카페/소매·팝업/기타), 계약기간(단기 2개월/장기)
- 결과 카드: 썸네일, 지역, 월 임대료, 업종 태그, "장비 패키지 포함" 배지
- 정렬: 낮은 가격순 / 최신 등록순

### 4.2 추천 위젯 (3단계, 모달 또는 별도 페이지)
1. 예산 구간 선택
2. 희망 업종 선택 (아이콘형: 카페/소매/팝업/기타)
3. 희망 시작 시기 선택 (즉시/1개월 내/미정)
- 완료 시 검색 결과 화면으로 이동하며 답변이 필터에 자동 반영
- 각 단계에서 "건너뛰기"로 이탈 가능

### 4.3 검색 결과 목록
- 홈과 동일한 카드 컴포넌트 재사용
- 상단에 적용된 필터를 칩(chip)으로 표시, 개별 삭제 가능
- 빈 결과 시: 안내 문구 + 필터 완화 제안 버튼

### 4.4 공실 상세 페이지
- 이미지 갤러리, 위치(지도), 면적, 월 임대료, 보증금, 선택 가능한 계약기간 옵션(예: 2/4/6개월)
- 업종별 장비 패키지 카드를 인라인으로 노출 (예: "카페 스타터 패키지 — 에스프레소 머신, 냉장고, 테이블 4세트" + 패키지 렌탈료)
- 하단 고정 바: "신청하기" CTA + 찜 버튼
- 상태에 따라 CTA 텍스트 전환 (§5 참고)

### 4.5 신청/상담 요청 폼
- 입력: 이름, 연락처, 희망 계약기간, 희망 시작일, 요청 메시지(선택)
- 제출 후: "운영팀이 24~48시간 내 연락드립니다" 안내 + 마이페이지 이동 링크
- 결제 정보는 입력받지 않음 (§2 결제 범위 결정에 따름)

### 4.6 회원가입 / 로그인
- 이메일 + 비밀번호 기반
- 비로그인 상태로 신청 폼 진입 시 로그인 화면으로 유도 후, 로그인 완료 시 원래 화면으로 복귀

### 4.7 마이페이지 — 신청 현황
- 리스트형: 공실 썸네일 + 상태 배지(대기중/연락중/확정/반려) + 신청일

### 4.8 마이페이지 — 관심 목록(찜)
- 찜한 공실 카드 그리드, 클릭 시 상세 페이지 이동

## 5. 예외 / 엣지 케이스

- **검색 결과 없음**: 조건 완화 제안 + 가장 가까운 대안 조건 자동 제시
- **마감된 공실 접근**: 상세 페이지에 "마감됨" 배지, 신청 버튼 비활성화, 유사 공실 대체 카드 노출
- **중복 신청**: 이미 신청한 공실은 "신청하기" 대신 "신청 현황 보기"로 버튼 전환
- **비로그인 상태에서 신청 시도**: 로그인 유도 후 원래 컨텍스트로 복귀
- **장비 패키지 미등록 업종**: "이 업종은 장비 렌탈 준비 중, 공실만 임대 가능" 안내로 대체
- **운영진 응답 지연**: 마이페이지에 "확인 중" 상태 유지 (오프라인 처리이므로 별도 에러 처리 불필요)
- **극단적 필터 조합으로 결과 0건**: 결과 없음 안내 + 추천 위젯 재시도 유도

## 6. 이번 스펙에서 제외한 것 (다음 스펙 후보)

- 건물주(임대인) 측 화면: 공실 등록 폼, 내 공실 관리 화면
- 운영자(관리자) 측 화면: 신청 현황 관리 대시보드, 장비 패키지 마스터 관리
- 위 두 축은 창업자 측과 동일한 "공실" 데이터 모델을 공유할 것으로 예상되나, 데이터 모델 자체는 이번 스펙에서 정의하지 않음 — 건물주/운영자 스펙 작성 시 함께 정의 필요
- 온라인 결제/정산 시스템
- 모바일 네이티브 앱
- 소셜 로그인 실제 연동 (UI 자리만 확보)

## 7. 다음 단계

- 이 스펙 승인 후, 구현 계획(implementation plan)은 별도로 writing-plans 절차를 통해 작성한다.
- 건물주 측, 운영자 측 화면은 별도 브레인스토밍 세션에서 독립된 스펙으로 진행한다.
