오른쪽(제안)에서 바뀐 것 5가지

  1. 헤드라인 줄바꿈 정리 — "까요!" 한 단어가 혼자 남는 걸 막기 위해 의미 단위로 줄을 나누고(keep-all), 폰트 크기를 22px→21px로 살짝 낮췄습니다. 문구 자체도 "되니까요!"→"되니까요"로 끝맺음을 조금 더 담백하게 다듬었습니다. 근거: 375px 모바일에서 실측 확인, span이 2줄로 쪼개지며 고아 단어가 발생
  2. 포인트 컬러 추가 (코럴 #FF6A4D) — 구조·정보(헤더, 배지, 텍스트)는 기존 네이비/블루를 유지하고, "시작하기" CTA·절감액 카드처럼 행동을 유도하는 지점에만 따뜻한 코럴을 씁니다. 신뢰는 네이비가, 친근함은 코럴이 맡는 구조입니다. 근거: 딥네이비 단일톤이 20-30대 타깃엔 "핀테크·은행 앱"처럼 읽힐 수 있음
  3. MVP 데모 배너를 경고에서 안내로 — 진한 다크 배경·굵은 대비를 옅은 그레이 배경·중간 굵기로 낮췄습니다. 문구는 그대로 유지했습니다(법적으로 필요한 고지라 삭제하지 않음). 이미 지난 피드백에서 footer 고지는 낮췄고, 이번엔 상단 배너도 같은 톤으로 맞춤
  4. 공간 사진 자리 추가 — "가짜 매물 아님" 고지는 그대로 두되, 히어로 하단에 대표 공간 이미지를 한 장 얹어 각인력을 높였습니다. (지금은 목업이라 그라디언트로 대체했고, 실제 반영 시엔 저작권 프리 스톡사진이나 실제 촬영 사진을 씁니다.) 근거: 현재 사이트는 카드 안에만 추상 SVG가 있고, 랜딩 첫 화면엔 이미지가 전혀 없음
  5. 비용 비교 카드는 그대로 유지 — 숫자와 레이아웃은 이미 효과적이라 손대지 않았고, 승자 카드(빈자리)의 강조색만 브랜드 블루→코럴로 바꿔서 "이득" 느낌을 더 뚜렷하게 했습니다. 정보 위계 자체는 문제 없었던 부분 — 색만 교체
